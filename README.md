# Chess Journey

The site behind [chessjourney.co.uk](https://chessjourney.co.uk): personalised posters drawn from a player's Chess.com or Lichess rating history.

- `index.html`: the shop, poster maker and checkout links
- `*/index.html`: search landing pages (gift, rating poster, Chess.com, Lichess)
- `hikaru.json`: compact example data from Hikaru Nakamura's public Chess.com games
- `social/`: slide images for scheduled social posts, published here so the posting service can fetch them

Netlify deploys `main` automatically; there is no build step.
